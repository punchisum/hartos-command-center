# Verification Loop

Do this before saying work is done.

## Check

- Changed files.
- Typecheck.
- Lint.
- Tests.
- Build.
- Manual smoke test instructions.
- Unresolved risks.

## Report

State what passed, what was skipped, why anything was skipped, and the remaining risk.
